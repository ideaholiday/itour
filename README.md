## ❓ COMMON QUESTIONS

### **Q: Can I edit the templates?**
**A:** Yes! Open any HTML file in text editor and:
- Change colors (#0B2545, #722F37, #D4A574)
- Change text (subject, body, CTA)
- Add/remove sections
- Change fonts
**Keep:** Email structure, UTM parameters, responsive design

### **Q: What if someone complains about frequency?**
**A:** You're sending 3 emails over 7 days (acceptable). Each focuses on different angle:
- Day 1: Features
- Day 3: Revenue
- Day 5: Urgency

### **Q: Can I send all 3 at once?**
**A:** No. Space them 3-5 days apart for best results. Spamming = low conversion.

### **Q: How do I track conversions?**
**A:** Brevo dashboard shows:
- Opens by hour
- Clicks by link
- Unsubscribes
- Bounces
Use UTM codes to track who signs up from which email.

### **Q: What if open rate is low?**
**A:** Try:
1. Different subject line (use Day 3 subject on Day 1)
2. Different send time (try 6 PM)
3. Check list quality (real tour operators?)
4. Warm up with text email first

### **Q: Can I personalize with names?**
**A:** Yes! In Brevo, use {{FIRSTNAME}} or {{EMAIL}} if your list has those fields.
