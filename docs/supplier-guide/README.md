## The portal in one minute

A supplier is a business that runs trips: transfers, day tours, packages, attractions or activities. In the portal they:

1. **Get verified** (KYB), so travelers can book them.
2. **List products** and set prices, seats and schedules.
3. **Receive bookings**, accept them, and assign a driver.
4. **Run the trip**: the driver checks the traveler's pickup OTP (one-time code), and the trip is completed.
5. **Get paid**: Idea Holiday keeps its commission and pays the rest to the supplier's bank.
6. **Grow**: public profile, reviews, QR codes, and paid profile plans.

**The golden rule:** Idea Holiday's system decides the price, the seats left and the booking status. A supplier cannot change the price of a booking that is already made, and nobody can type in a total by hand.

## How to use the advice boxes

Each chapter has boxes like this:

> **Tell the supplier:** advice you can pass on directly.

> **Team note:** internal detail. Don't read it out to suppliers as a promise.

> **Known gap:** the screen shows something that doesn't fully work yet. Chapter 9 has the full list.

## Words you will see

| Word | Meaning |
| :--- | :--- |
| KYB | "Know Your Business": checking that the supplier is a real business (PAN, GSTIN, licence, bank). |
| Listing / product | Something travelers can book, like "Goa Airport to North Goa hotel". |
| Option | A version of a product (for example "Standard option"). Seats and schedule are set per option. |
| Departure | One start time on one date, like 9:00 AM on 20 Oct. |
| Hold | Seats kept for 10 minutes while a traveler pays. |
| Cut-off | How long before the start time bookings stop. |
| SIC | Seat-in-coach: a shared vehicle, priced per seat. |
| Pax | Passengers. |
| OTP | The 6-digit pickup code only the traveler has. The trip can't start without it. |
| Payout | The money Idea Holiday pays the supplier after the trip. |
| Commission | Idea Holiday's share of the booking (30% by default). |
| Spotlight | A paid plan that shows one listing on the supplier's public profile. |
| Verified | A badge after a yearly business check. It can't be bought, only earned. |
