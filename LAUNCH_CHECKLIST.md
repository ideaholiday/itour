## 🔧 TROUBLESHOOTING

### **Email Not Showing Up?**
- [ ] Check spam folder
- [ ] Check if it went to Promotions tab (Gmail)
- [ ] Ask Brevo to resend test
- [ ] Check HTML for errors (broken tags)

### **Links Not Working?**
- [ ] Verify URLs in HTML file
- [ ] Check for typos in domain
- [ ] Test on mobile and desktop
- [ ] Make sure HTTPS (not HTTP)

### **Images Not Loading?**
- [ ] Check if image URLs are absolute (full path)
- [ ] Test if hosting server is online
- [ ] Try different image format
- [ ] Ask Brevo support

### **Low Open Rate?**
- **Check:** Is subject line compelling?
- **Check:** Send time correct? (Try 6 PM if morning failed)
- **Check:** List quality (2,500 real emails?)
- **Action:** Test different subject line in Day 3

### **Low Click Rate?**
- **Check:** Are CTAs clear? (Big buttons?)
- **Check:** Is value proposition clear?
- **Check:** Is urgency conveyed?
- **Action:** Use brevo_diwali_revenue_focus.html template (higher CTR)

### **High Bounce Rate?**
- **Check:** Email list quality (bounced emails = bad data)
- **Check:** Did you upload 2,500 tour operators or random emails?
- **Action:** Clean list, remove bounces, retry with valid emails
- **Contact Nidhi:** Verify data source accuracy

- Landing page may be confusing
- Sign-up form may have too many fields

- List may be cold/purchased

- Frequency may be too high
